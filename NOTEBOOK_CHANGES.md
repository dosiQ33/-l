## 📋 Обзор изменений

Создан новый notebook **`Simplified_CLTV_Comparison.ipynb`** - упрощенная версия для сравнения CatBoost и LightGBM без Optuna, churn и прогнозирования.

## ✅ Реализованные изменения

### 1. **Объединение сегментов (SEGMENT_GROUP)**

**Цель:** Уменьшить фрагментацию данных и улучшить устойчивость моделей

**Маппинг:**
- `1026 (MICRO) + 1027 (SMALL)` → **`SMB`**
- `1022 (MIDDLE) + 1023 (LARGE)` → **`CORPORATE`**
- `1028, 1040` → **`OTHER`**

**Результат:**
- Вместо 6 сегментов теперь 3 группы
- Больше данных на группу → лучшее качество моделей
- Меньше риска переобучения на малых сегментах

---

### 2. **Winsorization для обработки выбросов**

**Проблема:** Экстремальные значения MARGIN (-2.4 млрд ... +783 млн)

**Решение:**
- Применена **winsorization (1%, 99% перцентили)** для всех margin-признаков
- Обрезаются 1% крайних значений с каждой стороны

**Обработанные признаки:**
```python
MARGIN, MARGIN_LAG1, MARGIN_LAG2, MARGIN_LAG3
MARGIN_AVG_1M_LAG, MARGIN_AVG_2M_LAG, MARGIN_AVG_3M_LAG
MARGIN_AVG_6M_LAG, MARGIN_AVG_12M_LAG
```

**Новый признак:**
- `IS_NEGATIVE_MARGIN` - бинарный флаг для отрицательных значений

---

### 3. **Расширенные метрики качества**

Добавлены **10 метрик** вместо стандартных R² и MAE:

| Метрика | Описание |
|---------|----------|
| **R²** | Стандартный коэффициент детерминации |
| **MAE_млн** | Mean Absolute Error в миллионах |
| **RMSE_млн** | Root Mean Squared Error в миллионах |
| **MedAE_млн** | Median Absolute Error в миллионах |
| **sMAPE_%** | Symmetric MAPE - устойчивая процентная ошибка |
| **Weighted_R²** | R² взвешенный по важности клиента |
| **Weighted_MAE_млн** | MAE взвешенный по величине клиента |
| **Capture_Rate_10%** | % value в top-10% predicted клиентов |
| **Capture_Rate_20%** | % value в top-20% predicted клиентов |
| **Sign_Accuracy_%** | Точность предсказания знака (прибыль/убыток) |

**Почему это важно:**
- **sMAPE** - учитывает относительную ошибку для клиентов разного размера
- **Weighted метрики** - важнее точность для крупных клиентов
- **Capture Rate** - бизнес-метрика: насколько хорошо ловим VIP-клиентов

## ❓ FAQ

**Q: Почему убрали Optuna?**
A: Для первого сравнения достаточно default параметров. Optuna можно добавить после выбора модели.

**Q: Можно ли обучить только CatBoost?**
A: Да, измените `train_both_models()` чтобы пропустить LightGBM блок.

**Q: Как добавить новый сегмент?**
A: Измените `map_segment_groups()` mapping.

**Q: Что если данных мало?**
A: Уменьшите `Config.MIN_SAMPLES_PER_SEGMENT` или объедините больше сегментов.

**Q: Можно ли вернуть Optuna?**
A: Да, замените `get_default_params()` на оригинальный `optimize_hyperparameters_optuna()`.
